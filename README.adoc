= PHP RNP bindings

image:https://github.com/rnpgp/php-rnp/actions/workflows/test.yml/badge.svg["Build Status", link="https://github.com/rnpgp/php-rnp/actions/workflows/test.yml"]

This extension provides php bindings to the
https://github.com/rnpgp/rnp[librnp OpenPGP library].

== Requirements

This extension requires https://github.com/rnpgp/rnp[librnp] 0.18.1 or newer.
Version 0.18.1 is the security baseline: it fixes
https://github.com/rnpgp/rnp/security/advisories[CVE-2025-13470], a flaw that
caused PKESK session keys to be generated without cryptographically random
values.

PHP 8.2 or newer is supported (tested up to PHP 8.5).

== Documentation

Documentation for this extension is available in https://www.php.net/manual/en/book.rnp.php[PHP Manual].
